# Personal AI Brain: Master Engineering Plan v5.1

## 1. Vision: The Self-Evolving Digital Twin
To bridge the human-machine cognitive gap by synthesizing local-first data storage with advanced cognitive memory, real-time voice synthesis, and desktop-use agent frameworks.

## 2. The Building Bible (Project Governance)
The project is governed by a strict set of rules to prevent drift and ensure technical integrity.
* **The Constitution ([CLAUDE.md](/home/omar/personal_ai_brain_project/CLAUDE.md)):** Behavioral rules for agents.
* **The Status Tracker ([STATUS.md](/home/omar/personal_ai_brain_project/STATUS.md)):** Real-time phase/task progress.

## 3. Technology Stack (Locked)
* **Memory:** Letta (MemGPT) + LanceDB + pgvector.
* **Voice:** Faster-Whisper + Kokoro ONNX + Silero VAD.
* **Extraction:** pymupdf + watchdog.
* **Inference:** Ollama (Mistral-7B / Llama-3).

## 4. Implementation Roadmap (The 5 Phases)
1. **The Vault:** Local recursive RAG (nomic-embed-text).
2. **The Memory Engine:** Letta stateful agents + Daily Review cycle.
3. **Ingestion Pipelines:** Nexus-style web capture + automated folder watching.
4. **The Voice Layer:** 1.2s-1.5s latency local voice loop.
5. **Agency:** Bytebot sandboxed desktop control + Proactive assistance.
