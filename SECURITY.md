# Security Policy

## Reporting

Report security-sensitive issues privately to the maintainer instead of filing them as public issues.

## Scope

This project treats the following as security-relevant:

- privacy-router bypasses
- unsafe cloud routing of sensitive domains
- sandbox escapes
- command execution without confirmation
- secret leakage in logs or config

## Response Expectations

- acknowledge reports quickly
- reproduce and triage
- patch high-severity issues before public disclosure when possible
