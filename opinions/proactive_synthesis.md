# Opinion: Proactive Intelligence & Context Hygiene

## 1. Description
A second brain shouldn't just respond; it should anticipate. Proactive reach-outs and automated data synthesis ensure the user is always supported by their history.

## 2. Technical Implementation
* **Proactive Side-Panel:** Surface related notes based on active window content (similar to Microsoft Recall or Screenpipe).
* **Compression Cycles:** Periodically merging chat logs into "episodic summaries" to save context tokens.
* **Auto-Indexing:** Background agents that extract entities and wikilinks from new data.

## 3. Benefits
* **Reduced Cognitive Load:** The system brings the "right thing at the right time."
* **System Longevity:** Prevents the "infinite growth" problem from slowing down retrieval.
